# Dayflow — Demo Script

## Target demo

Keep the live demo around 3 minutes.

### 1. Admin login
Show the Admin dashboard.

Point out:
- total employees
- present
- absent
- on leave
- pending requests

### 2. Create employee
Admin creates an employee.

Show:
- employee information
- generated Login ID
- initial credential flow

### 3. Employee login
Switch to the employee account.

Show:
- employee dashboard
- profile
- current attendance status

### 4. Check In
Click Check In.

Show:
- status becomes Present
- attendance record appears

### 5. Request Time Off
Open Time Off.

Show:
- leave allocation
- Sick Leave/Paid Time Off
- date range
- request submission

Status becomes Pending.

### 6. HR approval
Switch to Admin.

Open Time Off.

Show:
- pending request
- Approve/Reject
- comment

Approve it.

### 7. Employee confirmation
Return to Employee.

Show:
- Approved status
- updated time-off information

### 8. Salary
Switch to Admin.

Open Salary Info.

Show:
- wage
- salary components
- deductions
- net salary

Emphasize that detailed Salary Info is protected for Admin.

## Backup

If the live network fails:
- use seeded demo data
- keep a second browser session logged into each role
- do not rely on manually entering many records during the demo
